# MedLuxLife – Ukrainian (uk) and Russian (ru) translation rules

Source: British English. Each string is one text node (or alt/placeholder/aria-label/title/button text) of a live page; translate ONLY the given strings.

## Style (both languages)
- Translate the meaning, not word for word: natural, fluent, grammatically perfect, like a premium clinic / travel agency. Calm, warm, trustworthy tone.
- Polite address, lowercase on websites: Ukrainian «ви / ваш», Russian «вы / ваш». Imperatives polite plural («Зв'яжіться з нами», «Свяжитесь с нами»).
- Medical advertising law (German HWG – applies to all languages): no promises or guarantees, no superlatives that are not in the source, no added "painless / risk-free / permanent". Keep cautious words ("usually" = «зазвичай» / «обычно», "may" = «може» / «может»).
- Keep facts exactly: numbers, ranges, units, ages, percentages. Decimal comma (1,5). Ranges keep the en dash without spaces ("2–4"). Sentence dashes become « — » (em dash with spaces). Quotes «…».
- Keep unchanged: MedLuxLife, WhatsApp, e-mail addresses, phone numbers, URLs, technique/brand names (FUE, DHI, PRP, NAD+, Choi, Vaser, SMAS, All-on-4, All-on-6, BBL, IVF, MRI/CT abbreviations may become МРТ/КТ), arrows (→, >), numbering ("1." at the start), HTML entities like &amp;.
- Leave a string exactly as it is (return the same text) when it is: German (legal texts, "Impressum", "Datenschutz", "AGB", "Widerrufsbelehrung", "Stornierungsbedingungen", German consents), a language name written in its own language ("English", "Deutsch", "Türkçe", "Українська", "Русский", "Français" …), a brand, a phone number or e-mail.
- Never name the partner clinic, hospital or doctors. "our partner hospital" = «наша лікарня-партнер» / «наша больница-партнёр», "our partner clinic(s)" = «наша клініка-партнер (клініки-партнери)» / «наша клиника-партнёр (клиники-партнёры)».
- Medical documents: never ask people to send documents to MedLuxLife; if the English says documents go directly to the doctor, keep exactly that meaning.
- Türkiye = Ukrainian «Туреччина», Russian «Турция»; Istanbul = «Стамбул».
- Russian: use «ё» where it is standard in medical/marketing texts only if needed for meaning (otherwise «е» is fine); Ukrainian apostrophe ʼ written as ' (as in «здоров'я»).
