# Quite Harbor: інструкції для Claude

Ти продовжуєш роботу над ф'ючерсною біржею **Quite Harbor**, яку почали в хмарній сесії Claude Code.
Тепер ти працюєш **на Маку власника**. Тут запущена бета, якою користуються живі тестувальники.

## Власник
- Пиши **українською**, коротко і простою мовою. Власник не програміст: давай покрокові
  інструкції «куди натиснути» і пояснюй, що змінилось для нього, а не як влаштований код.
- Власник шле скріншоти й тексти з терміналу. Розбирайся сам, нічого не вигадуй. Якщо щось
  не перевірив, так і скажи.
- Перед діями, які важко відкотити (видалення бази `data/*.db`, публікація назовні, реальні
  гроші), спитай.

## Що це
- USDT-M безстрокові ф'ючерси на 20 монет (BTC, ETH, BNB, SOL, XRP, DOGE, ADA, TRX, TON, AVAX, LINK,
  DOT, LTC, BCH, 1000SHIB, NEAR, UNI, APT, SUI, 1000PEPE). Лонг/шорт, плече до 100x, ізольована
  маржа, ціна маркування, ліквідація зі страховим фондом, reduce-only, кнопка «Закрити».
- Node.js ≥ 22.5 **без залежностей** (`http`, `crypto`, `node:sqlite`). На Маку стоїть Node 24.
- Логотип: `public/logo.svg` (кораблик + свічки), акцентний колір `#3dd9f0`.
- Повний опис, API й налаштування: `README.md`.

## Структура
- `src/engine.js`: матчинг і ф'ючерсна логіка: позиції, маржа, PnL, ліквідація, аудит.
- `src/server.js`: HTTP API, SSE-стрім + запасне опитування `/api/poll`, ліміти, адмінка.
- `src/bots.js`: маркетмейкер і тейкер (ліквідність у книзі).
- `src/broker/binance.js` + `hedger.js`: ціни Binance Futures (запасний варіант: спот) і дублювання
  чистої позиції клієнтів на Binance Futures Testnet (потрібні ключі в `beta.env`).
- `public/`: інтерфейс (`index.html`, `app.js`, `style.css`, `admin.html`).
- `beta.js`: запуск бети з публічним тунелем; `start-beta.command` / `.bat` для подвійного кліку.
- `test/`: тести (`npm test`), мок Binance; `loadtest.js`: навантаження.

## Правила коду
- Гроші тільки в `BigInt` з 8 знаками (`src/decimal.js`), жодних float у розрахунках.
- Кожна команда движка завершується `_commit()` (одна транзакція SQLite). Не ламай це.
- Після змін: `npm test` має бути зелений. Для змін у движку подивись `GET /api/audit`
  з localhost (або з заголовком `X-Admin-Token`): `ok: true` означає, що гроші й позиції сходяться.
- Зміни в інтерфейсі перевіряй у браузері.
- Коментарі в коді й тексти інтерфейсу українською.

## Бета: як запустити і перезапустити
```bash
cd exchange
node beta.js          # запускай у фоні, щоб він працював і далі
```
- Піднімає біржу на `127.0.0.1:8080` і відкриває публічний тунель. Адресу для користувачів
  друкує в рамці «БЕТА ЗАПУЩЕНА» і пише у `beta-url.txt`.
- **Cloudflare quick tunnel з мережі власника НЕ працює** (`api.trycloudflare.com` таймаут), тож
  скрипт після 3 спроб сам переходить на **localhost.run** (через `ssh`). Адреса `https://<id>.lhr.life`
  міняється після кожного перезапуску. Нову адресу завжди повідомляй власнику.
- Налаштування в `beta.env` (створюється при першому запуску): `PORT`, `ADMIN_TOKEN` (пароль
  `/admin.html`), `BROKER=binance`, `BINANCE_API_KEY/SECRET` (Futures Testnet), `TUNNEL=localhostrun`
  (одразу запасний тунель).
- База бети: `data/futures-beta.db`. **Не видаляй** її без дозволу, там акаунти тестувальників.
- Перед перезапуском зупини старий процес (`node beta.js` і його дочірні `node src/server.js`,
  `ssh ... localhost.run`, `cloudflared`), інакше порт 8080 буде зайнятий.
- Щоб Мак не заснув, поки триває бета: `caffeinate -d` в окремому фоновому процесі.
- Тунель localhost.run не передає реальні IP користувачів. Тому сервер у беті працює з
  `NO_LOCAL_TRUST=1`: адмінка доступна лише з паролем, а ліміти по IP вимикаються, коли IP невідома.
